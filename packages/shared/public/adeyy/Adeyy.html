Section 01 · How it works

How it works

Your QR code points to a short link. That link is a redirect you control — so you can change where it goes without touching the printed code.

01

Create

Paste a long link. Get a short adeyy.com link and its QR code, with a custom ending if you want one.

02

Print

Put it on flyers, windows, menus, vans. The ending is locked for life, so the printed code never goes stale.

03

Change

Point it somewhere new whenever you like. The change is live on the very next scan. Nothing to reprint.

my-cafe.com.au/winter-menu my-cafe.com.au/spring-menu
